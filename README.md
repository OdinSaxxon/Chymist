# Chymist
A free, fully local Windows desktop application built specifically for DIY perfumers who want a proper tool for managing materials, formulas, accords, batches, and IFRA compliance; all without the need for ANY spreadsheets.
What's included:
- 📋 Material inventory with vendor tracking, pricing, and IFRA override support
- 🧪 Formula Workshop with real-time IFRA compliance checking (51st Amendment, 262 standards)
- ⚗️ Accord Workshop for reusable palette components
- 📦 Batch tracking with component snapshots and note history
- 🛒 Purchase Order system with vendor fee logic and order history
- 📄 Document Vault with in-app PDF viewer
- 🔒 Fully local — no internet connection, no accounts, no data collection

Notes:
- Your data lives entirely on your machine in \AppData\Local\Chymist\
- IFRA data (51st Amendment) is bundled — no download needed

System requirements:
Windows 10 version 1809 (build 17763) or later
